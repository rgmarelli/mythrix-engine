## Phase 3 — Structured-data loader

**Rewritten to match the final name-based/inline-correspondence/optional-interpretation authoring format (FR18–FR22, RELATES_TO on Symbol->Symbol) — the original wording here (separate `relationships/` files, slug-based `RelationshipFile`) described the superseded design and was never implemented.**

- [x] **T10**. `core/loaders/symbol_schema.py`: pydantic models mirroring the YAML format — `TraditionFile`, `SourceFile`, `SymbolFile` (nested `PropertyEntry`, `InterpretationEntry` with `keywords`/`cites`/`attributes`/inline `corresponds_to: CorrespondsToEntry`). No separate relationship file type — correspondences are always inline (FR19). `interpretations` on `SymbolFile` defaults to `()` (FR22). *(FR4, FR18–FR22)*
  *Verify*: `tests/unit/test_symbol_schema.py` parses the Fool/Samekh worked examples from `spec.md` without error, confirms a bare (interpretation-less) symbol file is valid, and confirms a malformed/unknown-field file raises `ValidationError`. Passing.
- [x] **T11**. `core/loaders/symbol_loader.py`: `load_directory(root, store)` — two-pass design. Pass 1 recursively discovers `traditions/*.yaml`, `sources/*.yaml`, `symbols/*.yaml` under `root` (so `root` may span multiple domain directories at once), parses every file, and resolves every name-based reference (`interpretations[].tradition`, `cites`, `corresponds_to[].to`/`according_to`) via a tiered matcher — exact slug, then exact case-insensitive name, then a word-subset match (lets `according_to: "Golden Dawn"` resolve against a tradition named "Golden Dawn Kabbalah") — raising `IngestValidationError` (with file path) on any unresolved or ambiguous name, or duplicate slug, before anything is written. Pass 2 writes only if pass 1 raised nothing: traditions → sources → symbols (bare or with interpretations) → relationships, via `KuzuGraphStore`'s existing idempotent upserts. `cites` (a free-text string like `"Waite, Pictorial Key to the Tarot, p. 97"`) is resolved by treating the text after the last comma as the locator and the rest as a source query matched via the same tiered resolver. *(FR4, FR5, FR18, FR19, FR20, FR21, FR22)*
  *Verify*: `tests/unit/test_symbol_loader.py` loads `tests/fixtures/{tarot,kabbalah}/` end-to-end (spanning two domains, mirroring `spec.md`'s Fool/Samekh example exactly, including bare correspondence targets per FR22), confirms re-running is idempotent, and confirms a dangling `cites:` reference, an unresolvable `corresponds_to.to`, and an ambiguous `according_to` are each rejected with `IngestValidationError` and nothing written. Passing (40/40 unit tests green repo-wide).
